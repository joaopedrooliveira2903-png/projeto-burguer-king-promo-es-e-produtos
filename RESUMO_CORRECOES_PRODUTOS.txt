  Campos do Formulário:
  ├─ Nome da Promoção (obrigatório)
  ├─ Descrição (opcional)
  ├─ Desconto Percentual (opcional)
  ├─ Desconto Fixo em R$ (opcional)
  ├─ Data de Início (obrigatório)
  ├─ Data de Término (obrigatório)
  └─ Ativar Agora (checkbox)

  Validações:
  ✅ Nome não pode ser vazio
  ✅ Data de término > Data de início
  ✅ Pelo menos um desconto definido (% ou R$)
  ✅ Desconto percentual: 0-100%
  ✅ Desconto fixo: > 0

  Após Sucesso:
  ✅ Exibe mensagem de sucesso
  ✅ Limpa o formulário
  ✅ Redireciona para lista de promoções (2s)

  🎨 Design:
  ✨ Layout responsivo (mobile/tablet/desktop)
  ✨ Grid 2 colunas para desconto e data
  ✨ Inputs com foco visual em vermelho
  ✨ Checkbox estilizado
  ✨ Botões com hover effects

┌──────────────────────────────────────────────────────────────────────────┐
│ 🔧 LÓGICA DO NOVO ARQUIVO: js/nova-promocao.js                           │
└──────────────────────────────────────────────────────────────────────────┘

  Funções Implementadas:
  ┌────────────────────────────────────────────┐
  │ 1. mostrarMensagem(texto, tipo)            │
  │    → Exibe feedback (sucesso ou erro)      │
  │                                            │
  │ 2. cadastrarPromocao(event)                │
  │    → Valida dados do formulário            │
  │    → Insere no Supabase                    │
  │    → Trata erros                           │
  │                                            │
  │ 3. iniciar()                               │
  │    → Verifica autenticação                 │
  │    → Configura event listeners             │
  │    → Pronto para uso                       │
  └────────────────────────────────────────────┘

  Fluxo de Execução:
  1. Usuário preenche formulário
  2. Clica em "Criar Promoção"
  3. Valida dados (nome, datas, desconto)
  4. Cria objeto com dados
  5. Insere no banco via Supabase
  6. Verifica se houve erro
  7. Mostra mensagem de sucesso/erro
  8. Se sucesso: limpa e redireciona
  9. Se erro: exibe mensagem de erro

┌──────────────────────────────────────────────────────────────────────────┐
│ 🧪 COMO TESTAR                                                            │
└──────────────────────────────────────────────────────────────────────────┘

  TESTE 1: Criar Produto
  ─────────────────────────────
  1. Acesse: admin/produto.html
  2. Preencha o formulário com:
     • Nome: "Whopper com Queijo"
     • Descrição: "Pão especial, carne grelhada, queijo"
     • Preço: 25.90
     • Tipo: PRODUTO
     • Categoria: (selecione uma)
  3. Clique em "Cadastrar Produto"
  4. ✅ Esperado: Mensagem de sucesso verde

  TESTE 2: Criar Promoção
  ─────────────────────────────
  1. Acesse: admin/promocoes.html
  2. Clique em "Nova Promoção"
  3. Preencha com:
     • Nome: "Combo Família"
     • Desconto: 20 (percentual)
     • Data Início: hoje
     • Data Fim: daqui 7 dias
  4. Clique em "Criar Promoção"
  5. ✅ Esperado: Mensagem de sucesso + redirecionamento

  TESTE 3: Validações
  ─────────────────────────────
  1. Tente cadastrar sem preencher nome
  2. ✅ Esperado: Mensagem de erro

  1. Tente data fim < data início
  2. ✅ Esperado: Mensagem de erro

  1. Não selecione nenhum desconto
  2. ✅ Esperado: Mensagem de erro
